## Что изучили
1. **Статическую типизацию и вывод типов (`var`):** узнали, как компилятор фиксирует типы данных на этапе сборки.
2. **Sound Null Safety:** разобрались с nullable (`?`) и non-nullable типами, а также операторами `?.` и `??`.
3. **Синтаксис функций:** научились объявлять типы возвращаемых значений, использовать стрелочные функции (`=>`) и именованные обязательные параметры (`{required}`).
4. **Управляющие конструкции:** применили на практике циклы `for`, `for-in`, `while` и конструкцию `switch/case`.

## Ответы на вопросы

### 1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
В Python применяется **динамическая типизация** (типы переменных проверяются во время выполнения программы). В Dart типизация **статическая** — тип переменной известен и проверяется на этапе компиляции.  
* **Преимущество:** Это позволяет компилятору ловить огромный класс ошибок (например, передачу строки вместо числа) до запуска кода, предотвращая падения приложения в рантайме.

### 2. Что означает String?? Чем отличается от String?
В Dart по умолчанию включена система *Null Safety*, согласно которой переменная типа `String` гарантированно содержит текстовую строку и **не может** быть равна `null`.  
Символ `?` в объявлении `String?` делает этот тип *nullable* (допускающим значение `null`). То есть в такой переменной может лежать либо строка, либо ничего (`null`).

### 3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?
«Договорённость» в Python не защищает от случайных ошибок со стороны других разработчиков или невнимательности.  
Ключевое слово `final` в Dart обеспечивает **строгую защиту на уровне компилятора**. Если переменная помечена как `final`, её можно инициализировать лишь один раз во время выполнения программы. Любая попытка переназначить её позже вызовет ошибку компиляции, что делает код безопаснее.

### 4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
* **Позиционный параметр** передаётся строго по порядку своего объявления в функции, и его имя при вызове не указывается.
* **Именованный параметр** заключается в фигурные скобки `{}`. При вызове функции мы обязаны явно написать имя параметра. Модификатор `required` делает его передачу обязательной (без него будет ошибка компиляции).

**Пример вызова функции с именованным параметром:**
```dart
// Объявление функции
void greet({required String name}) {
  print('Привет, \$name!');
}

// Вызов функции
greet(name: "миша");
```
